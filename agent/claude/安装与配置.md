# 安装与配置

装好 Claude Code，并让模型请求真正通起来。日常操作见 [`日常使用.md`](./日常使用.md)。

> 本文基于 Claude Code 2.1.x、Linux / WSL。macOS 安装方式相同，但 shell 配置示例里的 `~/.bashrc` 要换成 `~/.zshrc`。Windows 原生的安装脚本、PowerShell 和编码差异见 [`../windows.md`](../windows.md)。

## 0. 三步开始

```bash
# 1) 安装
curl -fsSL https://claude.ai/install.sh | bash

# 2) 配模型接入（第 4 节，二选一：官方账号 / 公司网关）

# 3) 进项目目录启动
cd ~/code/你的项目
claude
```

第一次启动会让你选主题、确认工作目录，然后就能直接打字提问。

---

## 1. 前置条件

| 依赖 | 说明 |
|---|---|
| bash | Linux / WSL 自带 |
| 终端 | 任意现代终端；tmux / zellij 里也能跑 |
| Node.js | 官方安装脚本**不需要**；只有走 npm 安装才需要 22+ |
| Git | 强烈建议。项目在 git 仓库里，回退、review、diff 都靠它 |

> **WSL 用户**：先按 [`../wsl.md`](../wsl.md) 配好 WSL（镜像网络、代理、interop），再把 Claude Code 装在 **WSL 里**，不是 Windows 侧。

---

## 2. 安装

**官方安装脚本（推荐，不需要 Node.js）**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

装到 `~/.local/bin`，支持后台自动更新。如果提示找不到命令，把这个目录加进 `PATH`：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

**npm 方式（需要 Node.js 22+）**

```bash
npm install -g @anthropic-ai/claude-code
```

两种方式选一种即可，不要混装。

---

## 3. 验证

```bash
claude --version     # 能打印版本号就成
claude doctor        # 体检，装完建议跑一次
```

> `claude: command not found`：`source ~/.bashrc` 或重开终端刷新 `PATH`；仍不行就确认 `~/.local/bin` 在 `PATH` 里。

## 4. 模型接入（二选一）

这一步是最容易卡住的地方。按你拿到的账号类型选一种，**不要两套同时配**。

### 4.1 方式 A：官方 Anthropic 账号

适用于自己的 Claude Pro / Max 订阅，或从 <https://console.anthropic.com> 申请的 API Key。

```bash
claude          # 启动后输入 /login，按提示在浏览器里完成授权
```

用 API Key 时，不要把 Key 写在命令行（会留在 shell 历史里）：

```bash
read -rsp "API Key: " ANTHROPIC_API_KEY && echo
printf 'export ANTHROPIC_API_KEY="%s"\n' "$ANTHROPIC_API_KEY" >> ~/.bashrc
unset ANTHROPIC_API_KEY
source ~/.bashrc
```

### 4.2 方式 B：公司 / 自建网关

需要找对接人要两个值：**网关地址（BASE_URL）** 和 **访问令牌（AUTH_TOKEN）**。

#### 写在哪

| 写法 | 位置 | 适用 |
|---|---|---|
| **A. 配置文件（推荐）** | `~/.claude/settings.json` 的 `env` 段 | 只影响 Claude Code，不污染 shell |
| B. shell 环境变量 | `~/.bashrc` 里的 `export` | 想给别的工具复用同一个地址 / 令牌时 |

**同一个变量只写一处。** 两处都写且值不同时，`/status` 不会告诉你看的是哪个，排查会非常痛苦。

#### 常用变量

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://网关地址，找对接人拿",
    "ANTHROPIC_AUTH_TOKEN": "网关令牌，找对接人拿",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "网关提供的模型名",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "网关提供的模型名",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "网关提供的模型名",
    "ANTHROPIC_DEFAULT_FABLE_MODEL": "网关提供的模型名"
  }
}
```

| 变量 | 必填 | 作用 |
|---|---|---|
| `ANTHROPIC_BASE_URL` | ✅ | 网关地址，请求全发这里 |
| `ANTHROPIC_AUTH_TOKEN` | ✅ | 网关令牌，发成 `Authorization: Bearer` |
| `ANTHROPIC_API_KEY` | ❌ | 官方 API Key 用这个；走网关**别设**，容易和 token 打架 |
| `ANTHROPIC_MODEL` | 可选 | 启动时的默认模型 id；不设就看 `settings.json` 顶层的 `"model"`（`opus` / `sonnet` / `haiku` 是别名） |
| `ANTHROPIC_DEFAULT_<档位>_MODEL` | 建议全填 | `/model` 里各档别名分别指向哪个真实模型 |
| `ANTHROPIC_DEFAULT_<档位>_MODEL_NAME` | 可选 | `/model` 菜单里的友好名，例如 `Claude Haiku 5.5 (Bedrock)` |
| `ANTHROPIC_DEFAULT_<档位>_MODEL_SUPPORTED_CAPABILITIES` | 仅 Bedrock / Vertex / Foundry / Mantle | 声明第三方云上自定义模型的能力，逗号分隔，如 `thinking,interleaved_thinking`。**走 `ANTHROPIC_BASE_URL` 的网关时该变量被忽略** |

> - `ANTHROPIC_DEFAULT_*_MODEL` 填网关**实际支持**的模型名（几档填同一个也行）。填了不存在的名字，切模型时会报错。
> - 令牌不要写进命令行，也不要把带令牌的配置文件提交到 git。
> - `settings.json` 的 `env` 改动**必须重启 `claude`** 才生效。

#### 确认读到了

```bash
echo "$ANTHROPIC_BASE_URL"   # 用配置文件写法时这里是空的，正常
claude                       # 启动后看 /status 里的地址和模型
```

`/status` 里的地址还是 `api.anthropic.com`，说明变量没被读到时，按顺序查：

1. JSON 语法和缩进——写错一个逗号，整段 `env` 会**静默失效**；
2. 是不是两处都写、值还冲突；
3. 改完有没有重启 `claude`。

也可以直接在对话里问：

```text
你是什么模型？当前 API 地址是什么？
```

## 5. 上下文窗口与自动压缩

**前提**：Claude Code 内置一张「模型 → 上下文窗口」对照表。网关自带的模型（例如 `deepseek-flash`）不在表里，会被当成**未知模型**，默认只给 **20 万 token** 窗口——哪怕网关声明支持 1M 也不会自动认。所以「感觉上下文很小、老是压缩」通常不是错觉。

### 5.1 两个配置项，要一起设

在 `~/.claude/settings.json` 里加：

```json
{
  "env": {
    "CLAUDE_CODE_MAX_CONTEXT_TOKENS": "1000000"
  },
  "autoCompactWindow": 900000
}
```

| 配置 | 写在哪 | 作用 |
|---|---|---|
| `CLAUDE_CODE_MAX_CONTEXT_TOKENS` | `env` 段，**字符串** | 告诉 Claude Code 这个模型的窗口有多大，覆盖内置表 |
| `autoCompactWindow` | **顶层**，数字 | 聊到多少 token 触发自动压缩，合法区间 100000–1000000 |

**有效自动压缩窗口 = min(模型窗口, autoCompactWindow)**：

- 只设 `CLAUDE_CODE_MAX_CONTEXT_TOKENS=1000000`：窗口变成 1M，压缩窗口也跟着到 1M；
- 只设 `autoCompactWindow=900000`：会被 20 万的模型窗口卡住，白设。

所以前者负责「把窗口撑大」，后者负责「别等窗口满了才压缩」。建议后者比窗口小一截（1M 窗口配 900000），给生成摘要留余量。

### 5.2 关键坑：`modelPicker.behavesAs` 会让配置全部失效

`behavesAs` 的官方含义是「给一个本版本不认识的模型，指定一个它认识的模型 id」。**一旦映射成功，Claude Code 就不再把这个模型当“未知模型”**，于是 `CLAUDE_CODE_MAX_CONTEXT_TOKENS` 被跳过，窗口回落到被映射模型的值。

```jsonc
// ✗ 这样写，上面的 1000000 不生效
"modelPicker": {
  "options": [{ "model": "deepseek-flash", "behavesAs": "claude-sonnet-4-6" }]
}

// ✓ 去掉 behavesAs，保住“未知模型”身份
"modelPicker": {
  "options": [{ "model": "deepseek-flash", "label": "deepseek-flash" }]
}
```

> **原理**（逆向 Claude Code 2.1.282）：内部算窗口的函数结尾是
> `if (MAX_CONTEXT_TOKENS > 0 && 是未知模型) return MAX_CONTEXT_TOKENS; return 200000;`
> 「是否未知模型」的判断是：**能把模型 id 解析成任何一个内置 Claude 模型，就返回否**。`claude-sonnet-4-6` 是内置表里的真实 id，所以 `behavesAs` 指向它等于主动放弃未知模型身份。

### 5.3 验证（改完必须重启）

```text
/context        # 看窗口总量是不是 1M 量级
/autocompact    # 看自动压缩窗口的实际数值和生效来源
```

`/autocompact` 会显示窗口**从哪来**（`env` / `settings` / `model default` / 实验值）。**如果来源是 `model default`，说明你的配置压根没被读到**——回去查 JSON 语法和缩进。

### 5.4 一份完整的网关配置

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://网关地址",
    "ANTHROPIC_AUTH_TOKEN": "令牌",
    "ANTHROPIC_MODEL": "deepseek-flash",
    "ANTHROPIC_DEFAULT_FABLE_MODEL": "deepseek-flash",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-flash",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-flash",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-flash",
    "CLAUDE_CODE_MAX_CONTEXT_TOKENS": "1000000"
  },
  "modelPicker": {
    "options": [
      {
        "model": "deepseek-flash",
        "label": "deepseek-flash",
        "description": "Gateway custom model"
      }
    ],
    "replaceBuiltInOptions": true
  },
  "permissions": {
    "allow": [],
    "defaultMode": "auto"
  },
  "autoCompactWindow": 900000
}
```

### 5.5 相关开关（用得上再动）

| 变量 / 配置 | 作用 |
|---|---|
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW` | `autoCompactWindow` 的环境变量写法。优先级：这个 env > `settings` > `clientdata` > 实验值 > 模型默认；env 会压过 `/autocompact` 存的值 |
| `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` | 用百分比下调压缩阈值，例如 `70` = 用到 70% 就压 |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS` | 未知模型的单次输出上限默认只有 32000，用这个覆盖（输出上限和上下文窗口是两回事） |
| `DISABLE_AUTO_COMPACT` | 关掉自动压缩（手动 `/compact` 仍可用） |
| `DISABLE_COMPACT` | 连手动 `/compact` 一起关掉 |
| `CLAUDE_CODE_DISABLE_1M_CONTEXT` | 关掉 1M 上下文能力（排查用） |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | 设 `1` 关掉统计、报错上报等非必要请求，走内网网关时少一堆超时 |

> **别乱加 `[1m]`**：给模型 id 加后缀 `[1m]`（如 `claude-sonnet-4-5[1m]`）是**官方 Claude 模型**申请 1M 窗口的写法。网关自建模型加这个不一定被识别，还可能直接用不了。走网关就用 `CLAUDE_CODE_MAX_CONTEXT_TOKENS`。

## 6. shell

Linux / WSL 下没有需要配的东西：`bash` 工具和 `!` 命令都走 bash，`defaultShell` 保持默认即可。

只有一个例外：**Skill / 命令正文里的 `!` 注入块，`shell` 字段默认是 `bash` 且与平台无关**，不要指望它跟着你的登录 shell 变。

Windows 原生环境（PowerShell 工具、`defaultShell: "powershell"`、执行策略）见 [`../windows.md`](../windows.md) 第 3 节。

## 8. 安装 / 连接类常见问题

**Q：`claude: command not found`**
`source ~/.bashrc` 或重开终端；仍不行就确认 `~/.local/bin` 在 `PATH` 里，或跑 `claude doctor`。

**Q：安装时报错 / 403 / 提示不支持当前地区 / `curl | bash` 报语法错误**
Claude Code 有地区检测，**安装脚本本身也受限制**：受限地区访问 `https://claude.ai/install.sh` 会 302 到 `app-unavailable-in-region` 并返回 HTML，`curl -fsSL ... | bash` 只会报 `syntax error near unexpected token '<'`。安装这一步必须先有代理（WSL 代理见 [`../wsl.md`](../wsl.md) 第 2、4 节）。**网关配置只影响运行期 API，绕不过安装脚本的地区检测。**

**Q：连不上 / 一直转圈**
- 官方账号：`curl -I https://api.anthropic.com` 看网络和代理；
- 网关：`/status` 看地址；把 `ANTHROPIC_BASE_URL` 复制到浏览器试；
- 令牌过期就找对接人换。

**Q：上下文窗口太小 / 没聊几句就自动压缩**
网关模型默认只给 20 万窗口。按第 5 节设 `CLAUDE_CODE_MAX_CONTEXT_TOKENS` + `autoCompactWindow`，并确认 `modelPicker.behavesAs` 没有把模型映射成内置 Claude 模型。用 `/autocompact` 看实际值和来源。

**Q：WSL 里启动很慢（约 6 秒），或者 `rg` 用不了**
看 [`../wsl.md`](../wsl.md) 第 3 节的 interop 副作用——关掉 interop 后启动会变慢、ripgrep 可能失效，自行取舍。

**Q：Windows 原生环境怎么配**
见 [`../windows.md`](../windows.md)：PowerShell 工具、`defaultShell`、Hook 的 `.ps1` 编码坑都在那里。
