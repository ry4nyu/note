# 配置：模型接入

Pi 不认识"公司网关"这个概念，它只要求端点说一种它支持的 API。接入方式二选一：官方账号 / 自建兼容端点。

配置文件位置（都是 Linux 路径；Windows 原生环境那一份与 WSL **不共享**，见 [`../windows.md`](../windows.md)）：

| 文件 | 作用 |
|---|---|
| `~/.pi/agent/models.json` | 自建网关、自定义模型、上下文窗口 |
| `~/.pi/agent/auth.json` | `/login` 存下的凭据（**勿提交**） |
| `~/.pi/agent/settings.json` | 默认模型、默认思考等级等偏好 |

> 本文所有路径都是 Linux / WSL 下的 `~`。用 `PI_CODING_AGENT_DIR` 可以整体换目录。

---

## 1. 方式 A：官方账号 / API Key

在 Pi 里执行 `/login`，选 provider，按提示走订阅登录或存 API Key。凭据保存在 `auth.json`。

不想让 Pi 落盘凭据（CI 场景），改用环境变量：各 provider 的变量名见官方 Provider Authentication 文档（例如 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`）。

---

## 2. 方式 B：公司自建网关 / 任何兼容端点

写进 `~/.pi/agent/models.json`：

```json
{
  "providers": {
    "litellm": {
      "baseUrl": "https://网关地址，找对接人拿/v1",
      "api": "openai-completions",
      "apiKey": "$HS_LLMLITE_API_KEY",
      "models": [
        {
          "id": "deepseek-flash",
          "name": "DeepSeek V4.1 Flash",
          "reasoning": true,
          "input": ["text", "image"],
          "contextWindow": 1000000,
          "maxTokens": 393216,
          "cost": { "input": 0.3, "output": 1.2, "cacheRead": 0.006, "cacheWrite": 0 },
          "thinkingLevelMap": { "low": "low", "high": "high", "max": "max" },
          "compat": {
            "supportsStore": false,
            "supportsDeveloperRole": false,
            "maxTokensField": "max_tokens",
            "requiresReasoningContentOnAssistantMessages": true,
            "thinkingFormat": "deepseek"
          }
        }
      ]
    }
  }
}
```

关键点：

- **`apiKey` 只写变量名**：支持 `$NAME` / `${NAME}` 环境插值、字面值，或 `!命令`（请求时才执行）。**不要把令牌写死在文件里。**
- **`api` 决定按哪种协议发请求**：网关常见的是 `openai-completions`。写错了会报端点拒绝请求。
- **`models[].id` 必须跟网关暴露的模型名完全一致**，否则 `/model` 里选了也用不了。
- **`contextWindow` / `maxTokens` 决定 Pi 认为的窗口大小**，写小了会"没聊几句就压缩"（见第 5 节）。
- **`input`** 声明能不能吃图片；**`reasoning`** 声明是不是推理模型；**`thinkingLevelMap`** 把 Pi 的思考等级映射到网关支持的档位（映射到 `null` 表示该档位不支持）。
- **`cost`** 只影响 `/session` 里的费用估算，不填也能跑。
- **`compat`** 用于描述端点真实存在的差异，不要因为对方"声称兼容 OpenAI"就乱加。
- **改完不用重启**：打开 `/model` 会重新读这个文件。

本机的实际配置就是这一套，可以直接打开 `~/.pi/agent/models.json` 抄结构。

## 3. 凭据优先级与排查

从高到低：运行时 `--api-key` → `auth.json` 里存的 → `models.json` 里的 `apiKey` → provider 的环境变量。

```bash
pi auth check --provider litellm --json     # 看这个 provider 是否就绪
pi auth print-api-key --provider openai     # 给外部客户端取 key
```

`/model` 里看不到模型，多半是凭据解析不了：变量名写错、环境变量不在当前进程里（改完要重开终端）。

> ⚠️ `auth.json`、`models.json` 都**不要提交到 git**。用环境变量插值就是为了让密钥留在文件之外。

## 4. 默认模型与思考等级

不想每次手动选，写进 `~/.pi/agent/settings.json`：

```json
{
  "defaultProvider": "litellm",
  "defaultModel": "deepseek-flash",
  "defaultThinkingLevel": "medium",
  "enabledModels": ["litellm/*"]
}
```

| 设置 | 作用 |
|---|---|
| `defaultProvider` / `defaultModel` | 启动时用的模型 |
| `defaultThinkingLevel` | 启动时思考等级：`off` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max` |
| `modelThinkingLevels` | 按 `provider/modelId` 单独设启动等级 |
| `enabledModels` | 限定 `/model` 和 `Ctrl+P` 循环的范围，格式同 `--models` |

界面里改完按 `Ctrl+S` 也能存成默认。

## 5. 上下文窗口与自动压缩

Pi 判断"这个模型窗口多大"，**依据的是模型元数据**，不是猜的：

- 内置目录里的模型 → 用目录里的值（`pi update --models` 刷新目录）
- `models.json` 里的自定义模型 → 用你写的 `contextWindow`
- **没写 `contextWindow`** → 退回一个偏保守的默认值

所以"聊几句就自动压缩"这类问题，根因通常是**自定义模型没声明窗口**：网关支持 1M，Pi 却按小窗口算。

自动压缩默认开启，可调：

```json
{
  "compaction": {
    "enabled": true,
    "reserveTokens": 16384,
    "keepRecentTokens": 20000,
    "modelOverrides": { "litellm/deepseek-flash": { "keepRecentTokens": 40000 } }
  }
}
```

| 设置 | 默认 | 作用 |
|---|---|---|
| `compaction.enabled` | `true` | 是否自动压缩 |
| `compaction.reserveTokens` | `16384` | 给模型本轮回复预留的 token |
| `compaction.keepRecentTokens` | `20000` | 最近多少 token 原样保留、不做摘要 |
| `compaction.modelOverrides` | 无 | 按 `provider/modelId` 单独配 |

手动操作：`/compact` 压缩、`/new` 换话题、`/session` 看用量和费用。窗口够大时别关自动压缩，排查问题才临时 `enabled: false`。

另外 `cacheWarming`（默认 `"streaming"`）会在模型声明了缓存寿命、且预估省下的缓存未命中费用超过 $0.05 时保持 prompt 缓存热 —— 收益体现在费用上，`/session` 会显示下一次的决策。

## 6. 代理

- `models.json` 没办法配代理，代理走这里：
- `~/.pi/agent/settings.json` 的 `httpProxy`（**只能写在用户级设置里**）：
  ```json
  { "httpProxy": "http://127.0.0.1:10808" }
  ```
- 或者用 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量。

WSL 里镜像模式 + `autoProxy=true` 会自动拿到代理，见 [`../wsl.md`](../wsl.md) 第 2 节。

## 8. 常见问题

**Q：`/model` 里看不到我配的模型**
1）`api` 协议写对没有；2）`id` 跟网关模型名一致没有；3）`apiKey` 指向的环境变量在当前进程里有没有（`echo $HS_LLMLITE_API_KEY`）；4）`pi auth check --provider <name> --json`。

**Q：报端点拒绝请求 / 400**
十有八九是 `api` 或 `compat` 写错（比如该用 `max_tokens` 却让 Pi 发 `max_completion_tokens`）。

**Q：没聊几句就自动压缩**
按第 5 节检查这个模型的 `contextWindow`。手动救急用 `/compact`。

**Q：换环境后配置全"没生效"**
各环境的 `~/.pi/agent/` 互不共享，见 [`配置-运行环境.md`](./配置-运行环境.md) 第 3 节。
